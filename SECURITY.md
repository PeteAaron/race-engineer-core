# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report security issues by email to the maintainers listed in `pyproject.toml`. Include a description of the vulnerability, steps to reproduce, and any potential impact.

## Scope

This repository contains no authentication credentials, API keys, or user data. The live timing connection is read-only. The OpenF1 client uses a public, unauthenticated API.
